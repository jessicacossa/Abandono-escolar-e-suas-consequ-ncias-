# FUTURO. — Website educativo sobre abandono escolar

## Ficheiros
- `index.html` — conteúdo e estrutura do website.
- `style.css` — cores, layout e adaptação a telemóveis/computadores.
- `script.js` — funcionamento do menu em dispositivos móveis.

## Como visualizar
1. Extraia o ficheiro ZIP.
2. Abra `index.html` num navegador (Chrome, Firefox, Edge, etc.).
3. Para publicar no GitHub Pages, crie um repositório, carregue os três ficheiros para a raiz e active Pages nas definições do repositório.
